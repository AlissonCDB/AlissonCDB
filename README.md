## 🇧🇷 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** na FATEC Indaiatuba (Previsão de término: 12/2026). Tenho foco em criar soluções que unem interfaces modernas com arquiteturas de dados sólidas, transitando de forma eficiente entre o desenvolvimento web, mobile e a análise de dados.

### 🚀 Projetos em Destaque
* **Group Leveling:** Plataforma de gestão e agendamento de grupos de estudos. Desenvolvida com foco no engajamento de usuários utilizando Next.js e Supabase.
* **Além da Memória:** Aplicativo mobile para rastreamento de mídias (livros, filmes e séries) com uma identidade visual de estética *retro*. Construído com React Native e SQLite, integrado à API do TMDB.
* **VitalControl:** Sistema de backend robusto estruturado para o gerenciamento seguro de registros de usuários e dados farmacêuticos. Construído com NestJS e MongoDB.

## 🇺🇸 About Me

I am a **Systems Analysis and Development** student at FATEC Indaiatuba (Expected graduation: 12/2026). I focus on building solutions that bridge modern interfaces with robust data architectures, working efficiently across web development, mobile, and data analysis.
